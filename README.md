# THE ATLAS

A private digital atlas and personal travel archive.

The Atlas is a geographic reference library, travel research database,
adventure and experience database, destination encyclopedia, and personal
travel archive.

## Core Structure

The geographic hierarchy follows:

Continent → Country → Region → Destination → Places / Experiences / Food / Stays

The Atlas separates:

- **World Layer** — geographic information about places that exist.
- **Personal Layer** — places visited, planned trips, notes, memories, photos,
  and other personal travel records.

## Project Principles

- Geography comes first.
- Every country belongs to a continent.
- Countries contain their appropriate first-level regions.
- Regions contain destinations and experiences.
- Destinations contain places, experiences, food, stays, transport, weather,
  and costs.
- Personal records remain connected to their geographic location.
- Content should be editable through a universal owner-only editor.
- Archived records remain recoverable.
- Destructive deletion requires confirmation.
- The interface should remain clean and editorial outside edit mode.
